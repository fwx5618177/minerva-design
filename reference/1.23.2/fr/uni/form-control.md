# FormControl

Conteneur de champ qui relie un libellé, un contrôle, un texte d’aide et un message d’erreur, et partage l’état invalide / obligatoire / désactivé / lecture seule avec le contrôle.

Package: minerva-design@1.23.2

Renderer: uni

Locale: fr
