## Documentation

## MonthCalendar

Support: beta

Monday-first 42-day grid, month navigation/rollover, date selection with spillover-month navigation, ordered highlighted ranges, three cell sizes, event counts/list/activation and custom event-region labels. Native touch/view semantics differ from browser DOM semantics. Native devices do not expose document focus, inert, browser portals or File input APIs; H5 capabilities are specified separately. Device-runtime validation is still required. H5 supports roving arrows and Home/End day focus; native hosts use touch day selection. Component tests, H5 tests in happy-dom and the official Taro WeChat SDK compilation fixture pass. Physical-device E2E and other native targets are not verified.
