# Popover

A click-triggered floating panel for interactive content such as filters or account menus, anchored to its trigger. Unlike Tooltip it holds focusable content and manages focus, Escape and outside clicks itself; inside a Modal it closes first.

Package: minerva-design@1.20.0

Renderer: native

Locale: en

## Example: Basic usage

PopoverTrigger toggles the panel; focus moves inside and returns to the trigger on close. PopoverClose closes it. In a non-modal popover, Tab past the last element (Shift+Tab before the first) closes it and moves focus to the element after (before) the trigger; focus never loops inside.

Kind: internal-demo. The files below preserve the documentation example and its local dependencies. Documentation translation/runtime context may still be required; use a standalone recipe for an isolated application.
