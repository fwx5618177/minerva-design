# Graphique en aires

Des aires remplies pour montrer un volume dans le temps : lissées par défaut, superposées, empilées en un total ou en parts de 100 %. Survolez pour lire toutes les séries à un même x ; zoomez avec Ctrl / ⌘ + molette ou en pinçant.

Package: minerva-design@1.19.3

Renderer: wc

Locale: fr

## Example: Empilement à 100 %

percent ramène chaque pile à 100 % : la part de chaque source d'énergie au fil de la journée, avec des bords droits.

Kind: internal-demo. The files below preserve the documentation example and its local dependencies. Documentation translation/runtime context may still be required; use a standalone recipe for an isolated application.

External dependencies: minerva-design

Documentation context imports: none

### apps/docs/src/docs/pages/area-chart/wc/percent.html

```html
<minerva-area-chart
  id="mix"
  percent
  curve="linear"
  height="280"
></minerva-area-chart>

```

### apps/docs/src/docs/pages/area-chart/wc/percent.ts

```tsx
// `percent` scales every stack to 100%: the share of each source over time.
import type { MinervaAreaChart } from "minerva-design/web-components/chart";

const TEXT = {
  en: {
    solar: "Solar",
    wind: "Wind",
    hydro: "Hydro",
    hours: ["00:00", "04:00", "08:00", "12:00", "16:00", "20:00"],
  },
  zh: {
    solar: "太阳能",
    wind: "风能",
    hydro: "水电",
    hours: ["00:00", "04:00", "08:00", "12:00", "16:00", "20:00"],
  },
  ja: {
    solar: "太陽光",
    wind: "風力",
    hydro: "水力",
    hours: ["0:00", "4:00", "8:00", "12:00", "16:00", "20:00"],
  },
  fr: {
    solar: "Solaire",
    wind: "Éolien",
    hydro: "Hydraulique",
    hours: ["0 h", "4 h", "8 h", "12 h", "16 h", "20 h"],
  },
};

export function setup(root: HTMLElement) {
  const text =
    TEXT[document.documentElement.lang as keyof typeof TEXT] ?? TEXT.en;
  const chart = root.querySelector<MinervaAreaChart>("#mix")!;
  chart.series = [
    { name: text.solar, data: [0, 5, 40, 62, 35, 2] },
    { name: text.wind, data: [48, 52, 30, 22, 38, 55] },
    { name: text.hydro, data: [30, 30, 28, 26, 28, 30] },
  ];
  chart.options = { xAxis: { type: "category", categories: text.hours } };
}

```
