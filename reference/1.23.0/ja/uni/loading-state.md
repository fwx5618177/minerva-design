# LoadingState 読み込み状態

ページ・ルート・セクションの読み込み表示。装飾用の ProgressIndicator スピナーと表示ラベルを 1 つの polite なステータス領域にまとめます。

Package: minerva-design@1.23.0

Renderer: uni

Locale: ja
