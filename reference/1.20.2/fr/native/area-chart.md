# Graphique en aires

Des aires remplies pour montrer un volume dans le temps : lissées par défaut, superposées, empilées en un total ou en parts de 100 %. Survolez pour lire toutes les séries à un même x ; zoomez avec Ctrl / ⌘ + molette ou en pinçant.

Package: minerva-design@1.20.2

Renderer: native

Locale: fr

## Example: Base

Une série sur des valeurs x de type Date : le bord est une courbe lissée (monotone) qui ne dépasse jamais les données.

Kind: internal-demo. The files below preserve the documentation example and its local dependencies. Documentation translation/runtime context may still be required; use a standalone recipe for an isolated application.

External dependencies: minerva-design, react, react-i18next

Documentation context imports: none

### apps/docs/src/docs/pages/area-chart/native/basic.tsx

```tsx
import { useMemo } from "react";
import { useTranslation } from "react-i18next";
import { AreaChart, type ChartSeries } from "minerva-design/native";

function mulberry32(seed: number) {
  let a = seed;
  return () => {
    a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

const DAY = 24 * 60 * 60 * 1000;
const START = new Date(2026, 3, 1).getTime();

// Daily active users of an app over 90 days
export default function Basic() {
  const { t, i18n } = useTranslation("common", {
    keyPrefix: "docs.area-chart.data",
  });
  const locale = i18n.language;
  const series = useMemo((): ChartSeries[] => {
    const random = mulberry32(21);
    const data: [number, number][] = [];
    let level = 18_000;
    for (let i = 0; i < 90; i++) {
      level *= 1.004 + (random() - 0.5) * 0.01;
      const seasonal = 1 + 0.04 * Math.sin(i / 9);
      data.push([
        START + i * DAY,
        Math.round(level * seasonal * (0.985 + random() * 0.03)),
      ]);
    }
    return [{ name: t("dau"), data }];
  }, [t]);
  return (
    <AreaChart
      series={series}
      locale={locale}
      xAxis={{ type: "time" }}
      height={260}
      ariaLabel={t("dauAria")}
    />
  );
}

```
