## Documentation

## Rating

Support: beta

Controlled rating values on a ten-step scale, max mapping, native touch selection and read-only guards; dimension callbacks. Native touch/view semantics differ from browser DOM semantics. Native devices do not expose document focus, inert, browser portals or File input APIs; H5 capabilities are specified separately. Device-runtime validation is still required. Native half-star touch targets use explicit choices; hover preview and keyboard slider interaction differ. Component tests, H5 tests in happy-dom and the official Taro WeChat SDK compilation fixture pass. Physical-device E2E and other native targets are not verified.
