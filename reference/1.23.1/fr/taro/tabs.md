## Documentation

## Tab

Support: beta

Controlled/uncontrolled composition, disabled tabs, selected/force-mounted panels, shared-core first-enabled tab stop, semantic colors, variants, orientation and direction. Native touch/view semantics differ from browser DOM semantics. Native devices do not expose document focus, inert, browser portals or File input APIs; H5 capabilities are specified separately. Device-runtime validation is still required. activationMode and TabList loop affect browser keyboard focus only; native activation uses taps. First-enabled tab-stop fallback is implemented without changing controlled selection. Component tests, H5 tests in happy-dom and the official Taro WeChat SDK compilation fixture pass. Physical-device E2E and other native targets are not verified.
