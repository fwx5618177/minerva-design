# JsonField

Strict-JSON textarea with a format button and accessible syntax feedback; formatting preserves numbers, escapes and key order.

Package: minerva-design@1.23.1

Renderer: angular

Locale: en

## Example: Validate and format

Kind: internal-demo. The files below preserve the documentation example and its local dependencies. Documentation translation/runtime context may still be required; use a standalone recipe for an isolated application.

External dependencies: @angular/core, minerva-design

Documentation context imports: none

### example.ts

```tsx
import { Component } from '@angular/core';
import { MnJsonField } from 'minerva-design/angular';

@Component({
  selector: 'app-example',
  imports: [MnJsonField],
  template: `
<mn-json-field label="Configuration" [(value)]="value"/><pre>{{value}}</pre>
  `,
})
export class Example {
  value = "{\"name\":\"Minerva\",\"enabled\":true}";
}

```
