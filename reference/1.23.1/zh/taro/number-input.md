# NumberInput 数字输入

数字字段（spinbutton），支持方向键步进、可选步进按钮、min / max 限制和固定精度；值在失焦或按 Enter 时提交。

Package: minerva-design@1.23.1

Renderer: taro

Locale: zh

## Documentation

## NumberInput

Support: beta

Numeric parsing, draft validation/custom messages, decimal rounding, min/max clamping, optional steppers, allowEmpty fallback and inherited locking. Native touch/view semantics differ from browser DOM semantics. Native devices do not expose document focus, inert, browser portals or File input APIs; H5 capabilities are specified separately. Device-runtime validation is still required. Intermediate drafts commit on native blur/confirm; browser arrow-key stepping is not reproduced. Component tests, H5 tests in happy-dom and the official Taro WeChat SDK compilation fixture pass. Physical-device E2E and other native targets are not verified.
