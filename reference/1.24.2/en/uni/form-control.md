# FormControl

Field container that links a label, a control, help text and an error message, and shares invalid / required / disabled / read-only state with the control.

Package: minerva-design@1.24.2

Renderer: uni

Locale: en

## FormControl

Support: beta

Native field state wrapper; uni reactive inherited flags and authored label/helper/error sections. Editing controls inherit disabled/readonly with explicit false override. Component tests, H5 tests in happy-dom and the official uni-app WeChat SDK compilation fixture pass. Physical-device E2E and other native targets are not verified.
