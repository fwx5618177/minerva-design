Renderer: uni

## Documentation

## JsonField

Support: beta

Raw string controlled/default models including invalid drafts; localized blur validation, toolbar and format action, jsonc lexeme-preserving indentation/compact formatting, inherited field props, rows and textarea appearance. Component tests, H5 tests in happy-dom and the official uni-app WeChat SDK compilation fixture pass. Physical-device E2E and other native targets are not verified.
