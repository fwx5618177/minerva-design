Public CSS custom properties, design tokens and accessibility styles for the form components: AutoComplete, Cascader, Checkbox, FormControl, FormLayout, IconButton, Input, JsonField, KeyValueEditor, MonthCalendar, NumberInput, Radio, Rating, Select, Switch, TagInput, Textarea, TimePicker and Upload.

- **CSS variables**: each component documents a stable set of `--<component>-*` variables (e.g. `--input-height`, `--input-radius`, `--select-option-padding-y`, `--switch-track-width`, `--checkbox-size`, `--time-picker-cell-height`, `--icon-button-size`). They are read with fallbacks and never set on the component itself, so a value set on the element, any ancestor or `:root` applies (set the variables of portaled dropdowns on `:root` or the dropdown class). Existing overrides keep working: `--checkbox-*` and `--icon-button-*` are now documented, and the AutoComplete `--autocomplete-dropdown-bg` / `--autocomplete-option-hover-bg` / `--autocomplete-option-highlight-bg` hooks still work as aliases of the new `--auto-complete-*` names. Internal plumbing variables were renamed to a `--_<component>-*` prefix (`--_input-border`, `--_select-border`, `--_switch-accent`, `--_radio-accent`, `--_checkbox-accent`, ...).
- **Design tokens**: control heights of Input, Select, NumberInput, Cascader, TagInput tags, KeyValueEditor, MonthCalendar toolbar, TimePicker cells and IconButton follow `--control-height-*`, horizontal paddings `--control-padding-x-*`, the options of Select, AutoComplete, Cascader, TagInput and the TimePicker panel the row tokens (`--row-padding-y` / `--row-padding-x`); hard-coded radii, font sizes, z-indexes and transition durations now use `--radius-*`, `--font-size-*`, `--z-dropdown` and `--transition-*`, so the global density / radius / shadow / font-scale switches apply. The standard design renders as before, except the IconButton hover shadow, which now uses `--shadow-sm`.
- **Accessibility**: logical properties for RTL (input addons and actions, NumberInput stepper, Cascader and TimePicker column separators, Switch label spacing, TagInput list, text alignment) and mirrored direction-dependent visuals (Switch thumb travel, Cascader expand chevron, MonthCalendar previous / next chevrons, Rating half star); `forced-colors` styles for checked / selected / focused states conveyed by backgrounds or box-shadows (Checkbox, Radio, Switch track / thumb / active segment, Rating fill, Select / AutoComplete / Cascader / TagInput / TimePicker / MonthCalendar active items, Input / Textarea / NumberInput / Select / Cascader focus, Upload drag-over, IconButton pressed and outline); `prefers-reduced-motion` for the AutoComplete dropdown animation, the Checkbox / Radio error shake, the Checkbox / IconButton ripple and the Switch loading spinner.
