Icons: the set grows from 202 to 499 original icons in 23 categories (weather, nature, food, people, places, shapes, text, education, health, shopping, music, tools and sports are new), and some icons are drawn in colour. `IconDefinition` gets an optional `colors` array (one color per path, `undefined` keeps the drawing color), honored by the React, Vue, Angular and Web Components icons, `toSvg`, `drawIcon`, `IconCanvas` and the canvas icons. Colors apply to strokes only. The icons gallery shows the whole set on the page, with no nested scroll box. The home page hero buttons get a background.
