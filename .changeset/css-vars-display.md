Public CSS custom properties, design tokens and accessibility styles for the display and layout components: Avatar / AvatarGroup, Badge, Card, CodeBlock, DescriptionList, Divider, HtmlPreview, List, MonacoCodeEditor, Page, Prose, ResponsiveGrid, SplitLayout, Stack, Table, Tag, TextLink and VirtualList.

- **CSS variables**: each component documents a stable set of `--<component>-*` variables (e.g. `--card-padding`, `--card-radius`, `--table-cell-padding-y`, `--tag-font-size`, `--prose-link-color`, `--stack-gap`). They are read with fallbacks and never set on the component itself, so a value set on the element, any ancestor or `:root` applies. The `prose.scss` Sass mixin reads the same `--prose-*` variables. The existing overrides (`--card-bg-color`, `--card-border-color`, `--badge-bg`, `--divider-color`, `--avatar-size`, ...) keep working; `--avatar-size` set on an ancestor now resizes every avatar inside it (a numeric `size` prop still wins).
- **Design tokens**: Table cells, List items and DescriptionList rows follow the density row tokens (`--row-padding-y` / `--row-padding-x`; Table's `size` prop still scales them), radii use `--radius-*`, shadows `--shadow-*` and font sizes `--font-size-*` where they matched, so the global density / radius / shadow / font-scale switches apply. The standard design renders as before, except the Badge, Avatar hover and Tag elevation shadows, which now use `--shadow-sm` / `--shadow-md`.
- **Accessibility**: logical properties for RTL (table cell alignment, bordered table separators, stacked avatars, card footer, icon spacing, vertical dividers); `forced-colors` styles for Badge, Tag (including the pressed state), borderless Card variants, the interactive Card focus ring and sticky Table column edges; print styles (no scroll containers or sticky cells in Table / CodeBlock / Prose code, rows and cards kept whole, no shadows); `prefers-reduced-motion` for the Card entrance animations, Avatar / AvatarGroup / Tag / VirtualList motion.
