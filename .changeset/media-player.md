New `MediaPlayer` component: an audio / video player shell with themed custom controls — play / pause, skip back / forward (`skipSeconds`), a seek bar (`role="slider"`, localized `aria-valuetext` "1:23 of 4:56") showing the buffered range, `m:ss` / `h:mm:ss` time, mute and volume, a playback-speed cycle button (`playbackRates`), fullscreen and optional picture-in-picture, a loading spinner and a translated error state. The type is inferred from `mimeType` or the file extension (`type` overrides it); `startTime` resumes once on `loadedmetadata`; `title`, `poster`, `autoPlay`, `loop`, `muted` / `defaultMuted`, `preload`, `crossOrigin`, `controls={false}` (bare media element), `height` / `aspectRatio`. Events: `onTimeUpdate`, `onEnded`, `onPlay`, `onPause`, `onLoadedMetadata`, `onError`, `onRateChange`, `onVolumeChange`; imperative `play()` / `pause()` / `seek()` / `element`. Keyboard on the focused player: Space / K, ← / →, ↑ / ↓, M, F. Video gets a dark translucent overlay that fades while playing, audio a surface bar; dark mode and `prefers-reduced-motion` aware. On React (ref handle), Vue (`defineExpose`), Web Components (`<minerva-media-player>`, `minerva-*` events, `heading` slot, `no-controls`), Angular (`MnMediaPlayer`), and in beta on Taro, uni-app and WeChat (host `video` via `createVideoContext`, audio via `createInnerAudioContext`; mute only for video, device validation pending). React Native has no media element: `minerva-design/native` adds `MediaControls`, the same control bar driven by props, to wrap expo-video / expo-audio. `@minerva/core` adds the media helpers (`formatMediaTime`, `inferMediaType`, `nextPlaybackRate`, `mediaKeyAction`…).
