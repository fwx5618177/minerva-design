# Migrating from `@novel-isr/ui` to Minerva / 从 `@novel-isr/ui` 迁移到 Minerva

`@novel-isr/ui` 0.1.40 has been ported into `@minerva/lib-core`. Minerva is now
the single component library. This document maps **every** export of
`@novel-isr/ui` (`.`, `./theme-utils`, `./monaco`, `./styles.css`,
`./prose.scss`) to Minerva and lists every prop-name and behaviour difference.

`@novel-isr/ui` 0.1.40 已完整移植进 `@minerva/lib-core`，Minerva 成为唯一的组件库。
本文档把 `@novel-isr/ui` 的**每一个**导出（`.`、`./theme-utils`、`./monaco`、
`./styles.css`、`./prose.scss`）映射到 Minerva，并列出所有属性名与行为差异。

## TL;DR / 速览

Two ways to migrate / 两种迁移方式:

1. **Drop-in (compat)** — keep the code, change the imports (or make
   `@novel-isr/ui` a re-export shim). 不改业务代码，只换入口：

   ```ts
   // @novel-isr/ui/src/index.ts           -> export * from "@minerva/lib-core/compat";
   // @novel-isr/ui/src/theme-utils.ts     -> export * from "@minerva/lib-core/compat/theme-utils";
   // @novel-isr/ui/src/monaco.ts          -> export * from "@minerva/lib-core/compat/monaco";
   import "@minerva/lib-core/style.css"; // replaces @novel-isr/ui/styles.css
   import "@minerva/lib-core/compat.css"; // the --ui-* tokens, reset, .ui-stagger / .ui-enter-* utilities
   ```

   The compat entry exposes novel's exact names and prop shapes (proved by
   `packages/lib-core/src/compat/coverage.test.tsx`: 135 values + 163 types),
   renders novel's `ui-*` class hooks / `data-*` attributes, and passes novel's
   original (Chinese) built-in strings as explicit props. It is side-effect
   free (it never switches lib-core's locale).

   compat 入口提供与 novel 完全相同的导出名与属性形状，渲染相同的 `ui-*` 类名与
   `data-*` 属性，并以显式 props 传入 novel 原始（中文）内置文案；入口无副作用。

2. **Native** — move to Minerva's API (the "Minerva" column below). 迁移到
   Minerva 原生 API（见下表 "Minerva" 列）。

## Behaviour differences worth knowing / 值得注意的行为差异

Native Minerva API (compat keeps novel's behaviour unless stated) / 原生 API（除特别说明外 compat 保持 novel 行为）:

- **Booleans & sizes**: `isOpen/onClose` -> `open/onOpenChange`; `isInvalid/isRequired/isDisabled/isReadOnly` -> `invalid/required/disabled/readOnly`; `isLoading` -> `loading`; `sm/md/lg` -> `small/medium/large`.
- **Built-in strings** go through lib-core i18n (en / zh / fr); every one can be overridden by a prop. Compat passes novel's original strings explicitly.
- **Tooltip delay**: natively a `TooltipProvider` delay wins over the per-tooltip default; in novel (and compat) each Tooltip's own 300 ms default wins.
- **Checkbox / Radio / Switch** are native inputs: `ref` points to the `<input>` (novel: Radix `<button>`).
- **RadioGroup** `direction` row/column -> horizontal/vertical (`data-direction` kept); `value={null}` means controlled with no selection.
- **Badge**: native default solid with `role="status"`; compat subtle with `role="none"` (novel).
- **Alert**: role follows the variant; compat always `role="alert"`.
- **Avatar** initials: two letters or the first CJK character. **Tag / AvatarGroup** root is a `div` (novel `span`).
- **Pagination** always shows at least one page.
- **NavTree**: a disabled leaf no longer fires its handler nor keeps its `href`; a leaf without `href` is a `<button>`.
- **Tabs**: `onValueChange` -> `onChange`, `colorScheme` -> `color`.
- **Toast**: `ToastProvider position` camelCase (`topRight`; `data-position` still kebab-case); `toast.dismiss()` closes all; hover/focus pauses.
- **Drawer**: the description sits below the title.
- **CommandDialog**: can be uncontrolled (`defaultOpen`); options are not in the Tab order; query resets on open.
- **AppShell**: `onSidebarModeChange` no longer fires for no-op changes.
- **HStack / VStack** always force their direction.
- **StatusIndicator** (Minerva) is no longer focusable (it is a `role="status"` live region).
