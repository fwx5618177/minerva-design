# Brand artwork

The filled brand SVG components exported by `minerva-design/icons` use path data
from Simple Icons, as distributed in the Simple Icons snapshot bundled with
react-icons 5.7.0. No react-icons implementation or runtime dependency is included.
The marks are GitHub, React, Vue, Angular, WeChat, Svelte, Solid, HTML5, Apple,
Android and Linux.
